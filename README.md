# LichSOMA's Daily Calendar

## 배포 버전·설치 안내

- **현재 버전**: 1.1.0
- **Foundry VTT**: 13 / 14 (manifest의 verified: 14)
- **최신 릴리즈**: [LichSOMA's Daily Calendar Releases](https://github.com/LichSOMA/lichsoma-daily-calendar/releases/latest)
- **설치용 manifest**: [module.json](https://github.com/LichSOMA/lichsoma-daily-calendar/releases/latest/download/module.json)
- **수동 설치 ZIP**: [lichsoma-daily-calendar.zip](https://github.com/LichSOMA/lichsoma-daily-calendar/releases/download/1.1.0/lichsoma-daily-calendar.zip)

릴리즈 첨부 파일의 `lichsoma-daily-calendar.zip`을 사용하세요. GitHub의 자동 생성 `Source code` 압축 파일과는 구성이 다릅니다. ZIP에는 실행 파일·자원, README와 라이선스를 포함하며, 테스트·개발용 문서와 이전 압축 파일은 포함하지 않습니다. 개발·API 문서는 GitHub 저장소에서 확인할 수 있습니다.

업데이트 전 월드를 백업하고, 교체 후 월드와 브라우저를 다시 불러오세요. 함께 사용하는 LichSOMA 모듈도 이번 릴리즈 버전으로 업데이트하는 것을 권장합니다.

## 소개

Foundry VTT용 **시간대·일자** 캘린더 모듈입니다. 월드의 시간을 **오전 / 오후 / 심야**로 구분하고, 필요하다면 **일자**를 추가해 관리할 수 있습니다.

## 호환성·의존성

- **Foundry VTT**: v13 / v14 (manifest 기준, 검증 기준은 v14)
- **언어 지원**: 한국어 / 영어
- **권장 모듈**: [`lichsoma-taskbar`](https://github.com/LichSOMA/lichsoma-taskbar) (있으면 작업표시줄에 날짜 표시 자동 연동)

## 설치

1. 모듈 폴더를 Foundry 사용자 데이터의 `Data/modules/lichsoma-daily-calendar`에 배치합니다.
2. 해당 폴더 바로 안에 `module.json`이 있는지 확인합니다.
3. FVTT를 시작하고 월드의 **게임 설정 → 모듈 관리**에서 **LichSOMA's Daily Calendar** 항목을 활성화합니다.

Manifest URL이 제공된 배포본은 모듈 설치 화면의 **Manifest URL** 입력란을 사용할 수도 있습니다.

```text
https://github.com/LichSOMA/lichsoma-daily-calendar/releases/latest/download/module.json
```

## 주요 기능·사용법

스피커 셀렉터 활성 시 해당 테마를 자동 상속하고 캘린더 테마 설정을 잠급니다. 심플 라이트·다크도 코어 UI와 관계없이 셀렉터를 따릅니다. 자체 설정과 웹폰트는 보존하며, 셀렉터 비활성 시 심플은 기존처럼 코어 인터페이스를 따릅니다.

### 시간대 표시

- 오전은 기본 화면을 유지하고 오후·심야에는 노을·밤 오버레이를 부드럽게 적용합니다.

### 일자 카운트

- `1일차`부터 자유롭게 진행하고, 기준 날짜에 더해 실제 날짜로 환산해 표시합니다.

### 컨트롤 패널

- 우측 하단의 모래시계 아이콘을 클릭하거나, 씬 컨트롤(조명) 도구의 모래시계 버튼을 클릭하면 패널이 열립니다.
- **오전 / 오후 / 심야** 버튼으로 시간대를 직접 지정합니다.
- **◀ / ▶** 화살표로 시간대를 한 단계씩 이동합니다. (캘린더 활성 시 자정을 넘기면 다음/이전 날짜로 이어집니다.)
- **« / »** 화살표로 일자(`N일차`)를 직접 증감합니다.

시간대·일자는 GM만 변경할 수 있으며 월드 전체에 공유됩니다. 플레이어는 읽기 전용으로 확인합니다. 테마는 클라이언트별 설정이며 캘린더 웹폰트 CSS는 월드 설정입니다.

### 캘린더 위젯

- 좌측 상단에 월드 시간을 시각적으로 표시합니다.

### 테스크바 연동 (선택)

- [`lichsoma-taskbar`](https://github.com/LichSOMA/lichsoma-taskbar) 모듈이 활성화되어 있으면 작업표시줄 우측에 토글 버튼과 날짜가 표시됩니다.
- Taskbar 3.0.0 이상에서는 공개 버튼 API로 연동하며, 2.0.0 이상 구버전에서는 기존 버튼 삽입 방식으로 동작합니다. 캘린더 버튼은 외부 모듈 버튼 중 가장 오른쪽, 닫기·설정 등 기본 버튼보다 왼쪽에 표시됩니다. 패널의 열림 상태와 작업표시줄 재생성에도 연동됩니다.
- 날짜 조절 패널에는 현재 적용된 테마에 맞는 얇은 구분선을 표시합니다.

## 설정

- **테마**: **심플**(기본값), **터미널 그린**, **터미널 레드** 중에서 선택합니다. 단독 사용 시 심플은 각 사용자의 FVTT 기본 UI 라이트/다크 설정을 따르며, 터미널 그린·레드는 캘린더와 시간 컨트롤에 각각 녹색·적색 계열과 고정폭 글꼴을 적용합니다. 테마는 저장 즉시 적용되고, 지정한 캘린더 웹폰트는 유지됩니다. 화면 전체 시간대 오버레이와 다른 모듈의 테마는 변경하지 않습니다.
- **캘린더 기능 활성화**: 끄면 좌측 상단 위젯과 테스크바 날짜 표시가 사라지고, 시간대 컨트롤만 남습니다.
- **캘린더 기준 날짜 (YYYY/MM/DD)**: `1일차`에 해당하는 실제 날짜를 지정합니다. (기본값: `2000/01/01`) 예: 기준을 `2000/01/01`로 두고 `5일차`이면 `2000/01/05`로 환산되어 표시됩니다.
- **캘린더 웹폰트**: `@font-face` 등을 포함한 웹폰트 CSS를 직접 편집합니다. 적용할 글꼴과 단일 굵기·기울임·가변 폰트 축을 지정할 수 있습니다.
